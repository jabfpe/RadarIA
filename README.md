# Comparación de IAs 2026 · JABF

Un dashboard interactivo para comparar y visualizar las capacidades de diferentes modelos de Inteligencia Artificial en 2026.

## 📋 Descripción

Este proyecto presenta una visualización interactiva que compara múltiples modelos de IA incluyendo:

- **Claude** (Anthropic)
- **GPT** (OpenAI)
- **Gemini** (Google)
- **Meta AI** (Meta)
- **DeepSeek**
- **Qwen** (Alibaba)
- **ERNIE** (Baidu)
- **GLM** (Zhipu)
- **Kimi** (Moonshot)
- **Grok** (xAI)
- **Perplexity**
- **NotebookLM** (Google)
- **Mistral**
- **MiniMax**
- **Seed** (ByteDance)
- **Copilot** (Microsoft)
- **Nova** (Amazon)
- **Mimo**
- **Composer**

## 🎯 Características

- **Radar Chart Interactivo**: Visualiza las fortalezas de cada modelo en diferentes categorías
- **Sistema de Puntuación**: Evaluación en múltiples dimensiones de capacidad
- **Recomendaciones Personalizadas**: Sugiere el mejor modelo según tu caso de uso
- **Diseño Responsivo**: Funciona en desktop y móviles
- **Tema Oscuro**: Interfaz moderna con estética cyberpunk

## 🚀 Uso

Simplemente abre el archivo `index.html` en cualquier navegador web moderno:

```bash
# Opción 1: Abrir directamente
open index.html  # macOS
xdg-open index.html  # Linux
start index.html  # Windows

# Opción 2: Usar un servidor local
python -m http.server 8000
# Luego visita http://localhost:8000
```

## 📊 Categorías de Evaluación

El dashboard evalúa los modelos en diversas categorías como:
- Razonamiento y lógica
- Creatividad
- Codificación
- Análisis de datos
- Comprensión del lenguaje natural
- Y más...

- HTML5
- CSS3 (con variables CSS y animaciones)
